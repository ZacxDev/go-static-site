About This Proving Site

This site demonstrates the three template types available in go-static-site:

Plush Templates
Traditional template syntax with <%= %> expressions. Good for designers familiar with template languages.
Markdown
Write content in Markdown with YAML frontmatter. Perfect for blog posts and documentation.
Gomponents
Type-safe Go components with compile-time checking. Best for complex, dynamic UIs.

Helper Functions Available

The following helper functions are available in Plush templates:

  • text(key) - Get translation
  • startsWith(s, prefix) - Check string prefix
  • endsWith(s, suffix) - Check string suffix
  • contains(s, sub) - Check substring
  • upper(s) / lower(s) - Case conversion
  • markdown(s) - Render markdown
  • stringify(data) - JSON encode
